# GMC Lanka – Machine and Product Ordering System

A Full-Stack Web-Based Machine and Product Ordering System developed as a collaborative university software engineering project.

## 📌 Project Overview

GMC Lanka is a web-based platform designed to simplify the process of browsing, managing, and ordering machinery and related products.

The system provides an integrated platform for customers, administrators, and technicians, supporting product management, online ordering, payment processing, and service-related operations.

This project was developed collaboratively by a team of four members as part of our university software engineering project.

## 🎯 Project Objectives

- Develop a centralized platform for machinery and product ordering.
- Provide a user-friendly interface for browsing and purchasing products.
- Implement secure authentication and role-based access control.
- Simplify order and payment management.
- Support administrative operations and customer service management.
- Develop a maintainable and scalable full-stack application.

## ✨ Key Features

- **User Authentication:** Secure registration, login, and authentication.
- **Role-Based Access Control:** Separate functionalities for Customers, Administrators, and Technicians.
- **Product Management:** Browse, search, and manage machinery and products.
- **Category Management:** Organize products into relevant categories.
- **Shopping Cart:** Add and manage products before checkout.
- **Order Management:** Place orders and track order statuses.
- **Online Payments:** Integration with Stripe payment services.
- **Invoice Management:** Generate and manage order-related invoices.
- **Admin Dashboard:** Manage products, users, orders, and other system operations.
- **Appointment Management:** Support service-related appointment operations.

## 🏗️ Project Architecture

The application follows a client-server architecture.

- **Frontend:** React-based user interface for customers and administrators.
- **Backend:** Spring Boot REST APIs responsible for business logic, authentication, and data processing.
- **Database:** MySQL for persistent data storage.
- **Payment Integration:** Stripe for online payment processing.
- **Deployment Infrastructure:** Docker and AWS-based deployment environment.
